# Design system

Taken from the Dexter desktop app (its own CSS tokens), then adapted for a launcher.

## Colors

| Token | Value | Use |
|---|---|---|
| `--bg` | `#070708` | window ground |
| `--ink` / `--mute` / `--dim` | `#EDEDF0` / `#A3A7B0` / `#6C707A` | text: primary / secondary / disabled-hint |
| `--p` | `#8D45C7` | the accent: Play, Install, Join, active chips, toggles |
| `--p-hi` | `#9B55D6` | accent hover |
| `--p2` | `#B892FF` | accent text and icons on dark |
| `--ok` | `#4ADE80` | online / protection active / installed |
| `--danger` | `#E5484D` | close button hover |
| `--gold` `--silver` `--bronze` | `#F0C869` `#D9DCE3` `#D39A6C` | podium only |

Only one accent. Settings sheet is neutral black/white (no violet inside it).

## Type

- **Golos Text** 400/500/600/700, UI text, 14px base, nothing under 13px.
- **Pixelify Sans** 500/600/700, display only: hero and event titles, podium numbers, Play button, wardrobe name tag.
- Fonts are local files in `assets/fonts` (OFL licenses next to them), so the app works offline.

## Shape

- Panels (side panel, hero, wardrobe stage, event banner): **22px**.
- Cards (mods 20px, facts, boxes, wardrobe items, set groups): **18px**.
- Interactive controls (buttons, tabs, segmented controls, chips, search, toggles): **pill**.
- Exceptions: Play button 10px (blocky on purpose), instance picker on Home 12px.

## Surfaces

- **Card recipe** (`--card-fill`, `--card-edge`): a solid `#101012` base + a white sheen fading out by mid-card + a 1px gradient edge brighter at the top. Taken from the one Up app, made opaque so the grid does not show through.
- **Mod cards are opaque** (`#1A1A1D` to `#121213`) so the grid never shows through them.
- **Menus and the launch popup** are solid `#121214`.
- **Top bar:** no background, no outline. The tab container (pill) keeps the card recipe; the active tab is a solid white pill that slides.
- **Background:** a static 72px grid at 5% white (canvas in `app.js`, `data-grid`).

## Components worth knowing

- **Links drop-down:** one `Links` pill beside the logo in the top bar's left side; clicking it opens a menu with Support, Website and Discord (icon tile, name, small subtitle). They open in the system browser.
- **Home actions:** PLAY starts the game normally; **Join event** (ghost button with a red live dot) goes straight to the Dexter event server (`data-join`).
- **Wardrobe:** hats in the left column (3 per row), the 3D player in the middle with emotes as a pill row under it, pets in the right column (3 per row), capes in one horizontal swipe row along the bottom (trackpad, mouse wheel or the arrow buttons).

- **Play button:** purple block, 2px lighter border, inset top highlight and bottom shade, pixel texture of big 8px squares generated by `mosaic('#8d45c7', 8, 96, .1)`. Pressing moves it down 2px.
- **Cosmetics:** 3D player (skinview3d) on a card, one grid of items, tabs Capes / Hats / Pets / Emotes. Click to wear, click again to remove. Cape previews are the cape texture; hats, pets and emotes are rendered thumbnails (emotes animate on hover). Dexter cape = pixel mascot on black with violet trim (`DX_CAPE`).
- **Settings:** floating sheet over the current page; the page behind is dimmed and blurred.
- **Sign-in:** a 400x500 card that is the whole window.

## Motion

One easing curve: `--ease: cubic-bezier(.22,1,.36,1)` (soft ease-out, no overshoot).

| Thing | Motion |
|---|---|
| Top bar tab highlight | slides, 0.4s |
| Page change | fade + 12px slide toward the new tab, 0.3-0.4s |
| Hero event change | new image fades in over the old one, 0.9s; only the title/description/tag rise 8px. The two buttons (Play, instance picker) do not move or animate |
| Cards appearing | fade + 8px rise, 0.45-0.6s, tiny stagger |
| Toggles, buttons, hover | 0.15-0.3s color/opacity, press = scale .97 |
| Menus, popups | fade + 4-8px, 0.25-0.4s |
| Side panel in/out | width 0.45s |

Rules: nothing bounces, nothing loops except the live dot, spinners and the skeleton shimmer. `prefers-reduced-motion` turns all of it off.

## Windows

- Sign-in: 400x500, not resizable.
- Launcher: 1280x800, min 1100x700, resizable, maximizable (corners square off when maximized via `body.max`).
- Frameless; the window buttons are drawn in the top bar (`.wctl`).

## Images

- Event banners: 16:9, about 1920x1080, `assets/events/*.jpg`. Keep the left third calm: the title and buttons sit there over a dark gradient.
- Dexter server card: `assets/servers/dexter.jpg`.
- Logo files: `assets/dexter-mark-dark.svg`, `assets/dexter-wordmark-dark.svg` (white on transparent).
- App icon: `assets/icon.png` (1024x1024, rounded square with shadow). `assets/icon-source.png` is the flat artwork.

- **Skins:** a **Skins** button sits top right on the player card (where the refresh button was) and opens a pop-up with: an Upload skin card (accepts several 64x64 PNGs at once), then one card per saved skin with a front preview, in a two-column grid. One click wears it on the player model and in the top-bar head; click again to go back to the account's own skin; hover shows a delete cross. The worn skin is stored per account (`skin` in `accounts.json`); applying it in game (Mojang upload for Microsoft accounts, in-game loading for offline ones) belongs to the launch code.
- **Text fields:** no coloured focus outline; a focused field just gets slightly lighter with a thin white ring.
- **Drop-down motion:** every drop-down (Links, account, instance, Skins pop-up) grows out of its own button: scale .8 + 8px slide from the button's corner on an expo-out curve (`--pop`), rows follow with a 40ms stagger, and closing is a quicker shrink back. Reduced-motion users get a plain fade.
